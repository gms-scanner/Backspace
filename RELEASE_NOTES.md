# Backspace  dev-3.0-beta

Backspace dev-3.0-beta is the first public 3.0 beta release for Minecraft
Forge 1.12.2.

## Included

- Modern NanoVG ClickGUI with rounded cards, glow treatment, search, module
  inspector, category navigation, and HUD access.
- Backspace title menu and brand assets.
- Full source, Gradle wrapper, build workflow, and bundled source-build
  dependency.

## Install

1. Download `backspace-dev-3.0-beta.jar` and
   `OneConfig-1.12.2-forge.jar` from this release.
2. Put both files in the same Minecraft 1.12.2 Forge `mods` folder.
3. Launch Forge `14.23.5.2859` with Java 8.
4. Press `Right Shift` or run `/backspace` in-game.
