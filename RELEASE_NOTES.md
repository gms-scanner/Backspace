# Backspace dev-4.0-beta

Backspace dev-4.0-beta updates the Minecraft Forge 1.12.2 client with a pixel-styled module browser and new module controls.

## Highlights

- Yellow and black category windows with scrolling module lists, filled pixel toggle circles, and right-click settings.
- Inventory HUD showing 36 slots and stack counts in a draggable editor panel.
- AutoTotem offhand crystal mode switches back to a totem at configured health or when crystal threat is detected; CrystalAura supports offhand placement.
- DIESP highlights selected dropped items in loaded chunks using a searchable picker.
- PingSpoof, WhisperSpam, and BoatPhase modules.

## Install

1. Download `backspace-dev-4.0-beta.jar` and `OneConfig-1.12.2-forge.jar`.
2. Put both in the Minecraft 1.12.2 Forge `mods` folder.
3. Launch Forge 14.23.5.2859 with Java 8. Press Right Shift or run `/backspace`.

The build artifact checksum should be calculated from the published release asset.
