# Backspace dev-4.0.1-beta

This beta fixes the pixel ClickGUI layout and adds controls for its appearance.

## Fixes

- Right-click a module to expand its settings directly below that module in the same category window. The selected row moves to the top when needed so the controls remain visible.
- Remove text shadows from the pixel ClickGUI for crisp category and module labels.
- Add a GUI Editor button with four themes (Gold, Red, Mint, Blue) and adjustable category-window opacity. Both preferences persist in the client config.

## Install

1. Download `backspace-dev-4.0.1-beta.jar` from this release and the required [`OneConfig-1.12.2-forge.jar`](https://github.com/gms-scanner/Backspace/releases/download/dev-3.5-beta/OneConfig-1.12.2-forge.jar) dependency.
2. Put both in the Minecraft 1.12.2 Forge `mods` folder.
3. Launch Forge 14.23.5.2859 with Java 8. Press Right Shift or run `/backspace`.
